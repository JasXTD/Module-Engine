Browser extension · Chrome, Edge, Firefox

Ad blocking and userscripts, each with its own switch.

Module Engine filters ads and trackers with the browser's built-in rule engine and runs only the userscripts you have reviewed. Turn either one off without touching the other. There is no account and no telemetry, and the filter lists ship inside the extension.

What it does

Two modules with separate switches, plus the protections and tools around them. Everything runs inside the extension.

Ad and tracker filtering

Network rules run in the browser's own rule engine (declarativeNetRequest). Bundled EasyList and EasyList China snapshots add element hiding and advanced hiding rules. Add blocked or always-allowed domains, request filters and your own hiding rules, or pick an element on the page.

||ads.example^$third-party
news.example##.ad-slot
news.example##div:has-text(Sponsored)

Protection beyond filters

An optional per-site guard stops pop-ups, embedded-frame takeovers and redirect chains before their first request. Separate switches block new notification requests, install-to-play overlays and fake Play or Download buttons placed by ads. Ordinary downloads keep working.

Userscripts you review first

Import, write or install .user.js files from a URL. You see the source and the access a script asks for before it runs, and new scripts start switched off. Daily checks install an update on their own only when it needs no new access; anything wider waits for your review.

// ==UserScript==
// @name      Reader tweaks
// @match     https://news.example/*
// @grant     GM.getValue
// ==/UserScript==

GM APIs, both spellings

Storage and change listeners, menu commands, cross-origin requests, element and tab helpers, clipboard, notifications, downloads and scoped cookie access, as GM_* and GM.*. Files from @require and @resource download only when you choose Prepare dependencies.

Appearance

A system, light or dark theme for the popup and every Module Engine page, with seven accent colours or any colour you pick. Optionally, light websites get a dark version while the theme is dark, with per-site exceptions.

Logs and agent debugging

A local activity log, and optional network capture that records request details without headers or bodies. An opt-in local MCP server lets an AI agent read status, scripts and errors after you approve it. With a second approval it can propose script changes that wait for your review.

Module Engine is the only one here that blocks ads and runs userscripts in one extension. Each of the others does one of those jobs, and several do it more completely.

Install from source

Module Engine isn't in any store yet. Load the folder that contains manifest.json.

Chrome and Edge

  1. Open chrome://extensions or edge://extensions
  2. Turn on Developer mode.
  3. Select Load unpacked and choose the folder that contains manifest.json.
  4. Open Module Engine from the extensions menu.

To run userscripts, also turn on Allow User Scripts on the extension's details page. After updating the source, select Reload on the extensions page, then reload open tabs.

Firefox

  1. Open about:debugging#/runtime/this-firefox
  2. Select Load Temporary Add-on.
  3. Choose the folder's manifest.json.

A temporary add-on is removed when Firefox restarts. A permanent install needs Mozilla signing.

Needs Chrome or Edge 121 or later, or Firefox 128 or later. The optional MCP server also needs Node.js.

Privacy and limits

  • No telemetrySettings, scripts, cached dependencies and logs stay in the browser's extension storage. Nothing is sent to the project.
  • Lists update from their publishersWhile Community lists is on, EasyList and EasyList China are downloaded as often as they ask, without cookies or a referrer, and converted on your computer. Generic hiding changes only with a new release. You can turn updates off in My lists.
  • Reported threats are opt-in and expireOff until you turn it on, the threat layer blocks 24 hosts from dated public reports and switches itself off on 28 February 2027. It is not full malware protection.
  • Filtering is never completeLists can miss ads or affect legitimate pages, and sites change. Video sites can show ads that rules cannot separate from the video.
  • Scripts can see what they matchAn enabled script can read its pages, and a network grant lets it send data. Review the code and access before you turn one on.
  • Dark websites are an approximationThe website theme inverts colours with a filter, so some images, logos and dimming layers look different from a site's own dark design.
