Module Engine UI refresh

Popup and Modules & scripts page. Switches, tabs, the script list and the editor respond so you can feel the states. Blue numbers match the notes under each design.

1 · The three page buttons

Modules & scripts, My lists and Activity log are bold text in the popup footer and plain text in each page's side menu, so nothing says they can be clicked. They become real buttons with an icon, an edge and a hover state. On narrow pages they turn into three equal buttons instead of a line of text.

2 · Popup

Same content and order. Scroll inside the new popup, and try the master switch and the Filters / Domains tabs.

  1. 1Page buttons. Icon, edge and hover. Short labels fit one line; the full page name stays in the tooltip and accessible name.
  2. 2Master switch says what it is. A visible ON / OFF label beside the large switch.
  3. 3Site actions. Icons, left-aligned text and the same height, so the pair reads as two choices. A status pill shows whether this site is protected or paused.
  4. 4Tabs. The selected tab is a raised chip; before, it was a slightly darker grey that was hard to see in light mode.
  5. 5Userscripts row. A card with its own Manage button and live status, not text with a faint ›.

3 · Modules & scripts page

Shown at 1180 px and scaled to fit this window. Try both module switches, pick another script, and type in the source to see the unsaved-draft state.

  1. 1Side menu. Each page is a button with an icon tile; the current page is filled with the accent colour.
  2. 2One switch per module, top right. The status pill sits beside it, and the separate “Enable ad blocking” text label is gone. The icon greys out when a module is off.
  3. 3Module actions. Real buttons with icons, plus a shortcut to My lists. The userscripts card shows counts as chips.
  4. 4Library. New and Import share one row (the .user.js file type moves to Import's tooltip), search has an icon, and every script shows an On / Off pill instead of small grey text.
  5. 5Run this script moves from the bottom of the editor to its header, next to the name and the Saved / Unsaved state. It is greyed out while there are unsaved changes, as it is today.
  6. 6Script details become a labelled table (Sites, Timing, Frames, World, APIs) instead of loose lines.
  7. 7Save replaces “Save disabled”, which read like a greyed-out button. The hint beside it says saving turns the script off. Disabled buttons are neutral grey, never faded lime, and Delete is always red.
  8. 8Bug fix: opening a script showed the editor scrolled to the end of its longest line (the old screenshot starts at “serScript==”). It will open at the top-left.
  9. 9Supported features becomes a full-width row with a chevron that turns when opened.

4 · What changes and what stays

Changes

  • Shared button, tab and side-menu styles in ui.css; My lists and Activity log get the new menu and buttons too.
  • Inline SVG icons in the HTML (no icon font, no downloads).
  • Popup and Modules & scripts layout in popup.css, manager.css and their HTML.
  • manager.js: details table, On / Off pills, scroll reset, Save hint text.

Stays the same

  • Every element id the scripts and tests use, and all behaviour: saving still stores scripts off, switches still call the same messages.
  • Colours, fonts, light and dark themes.
  • Popup size (350 × 600 maximum) and page order.
