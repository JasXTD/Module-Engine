    Supported userscript features

    Metadata: @name, @namespace, @version, @description, @match, @exclude-match, @run-at and @noframes. Scripts use separate isolated worlds by default. @inject-into page is available only with @grant none.

    APIs: GM.info / GM_info, GM.addStyle / GM_addStyle, and asynchronous GM.getValue, GM.setValue, GM.deleteValue and GM.listValues. Values are local and private to each script.

    This is a focused userscript manager, not full Violentmonkey compatibility. Legacy synchronous storage, privileged network requests, @include, @require and @resource are unsupported. The editor reports unsupported features before saving. Disabling prevents future runs; it cannot undo JavaScript that already ran.

    Only enable scripts whose code and site access you trust. Scripts can read and change the pages they match. Module Engine does not fetch scripts; a script you enable can itself make web requests.
