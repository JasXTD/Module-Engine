Edit network filters

One filter per line, up to 500 rules. ||cdn.example.test/sponsor/*$script,domain=news.example.test blocks matching scripts requested by that site or its subdomains. Prefix a filter with @@ to add an exception.

Supported syntax

Use ||host^, ||host/path* or |https://host/path. A final | requires the URL to end there. * matches any text; ^ matches a URL separator or its end. Hostnames include subdomains; absolute URLs keep their exact host and scheme.

Options after $: script,image,stylesheet,font,media,object,subdocument,document,xmlhttprequest,xhr,ping,websocket,other; prefix a type with ~ to exclude it. Add third-party, first-party or match-case. Without type options, page loads are included.

domain=site.test|~shop.site.test restricts the initiating frame's site, which can differ from the top page. Blank lines and ! comments are allowed. Regexes, redirects, scripts, remote includes and unknown options are rejected. Always Allowed Domains and full site pauses take precedence over these filters.

Custom hiding rules

One rule per line: example.com##.sponsored-card hides a selector; example.com#@#.sponsored-card exempts that exact selector. Sites include subdomains. Up to 500 rules. No network requests are added or allowed.

Advanced example: example.com##.label:has-text(Sponsored):upward(1) hides the label's parent. Literal text only; no regexes or scripts. Child matching supports :has() with a text filter inside it. Ancestor selection accepts 1–10 levels or a CSS selector within ten levels.
