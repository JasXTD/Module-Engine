        Supported userscript features
    
        
      
        Metadata and timing
        @name, @namespace, @version, @description, HTTP(S) @match / @exclude-match, URL globs or bounded /regex/ rules in @include / @exclude, @run-at and @noframes. Matching supports http*, host wildcards, ports, IPv6, internationalized hosts, fragments and .tld suffixes. Timing supports document-start, document-body, document-end (the default) and document-idle. Scripts use separate isolated worlds by default. Page mode can combine unsafeWindow with granted GM APIs.
        
      
        Execution compatibility
        @grant unsafeWindow exposes the actual page window in page mode and the isolated global in content mode. Wrapped @inject-into auto scripts try page first and fall back to content if page startup is blocked; runtime errors never trigger a second run. Older saved auto scripts stay isolated until individually re-enabled. Page code can interfere with a page script, observe its data or invoke its granted helpers. Use content mode for isolation. @top-level-await enables an async function body. @unwrap runs raw global code, ignores grants and cannot combine with top-level await or document-body; its auto mode stays isolated. It accepts every scope wrapped scripts accept; scopes the browser cannot check exactly run a pre-check first, so excluded pages run none of its code.
        
      
        Cookies
        GM_cookie / GM.cookie provides list, set and delete with callbacks, or promises when no callback is supplied. Requires the exact grant and optional helper access. Reads and changes include HttpOnly cookies. Access defaults to the current host; other hosts require @connect. Only the calling tab's cookie store is accessible. partitionKey reaches only the tab's own top-level partition; Firefox also accepts its own firstPartyDomain. See the user guide for options and bounds.
        
      
        APIs
        GM.info / GM_info, GM.addStyle / GM_addStyle, GM.addElement / GM_addElement and GM.openInTab / GM_openInTab; getValue, setValue, deleteValue, listValues and their bulk getValues, setValues and deleteValues forms; addValueChangeListener / removeValueChangeListener; registerMenuCommand / unregisterMenuCommand. Request each API with @grant, using GM.name or GM_name.
        
      
        Elements and tabs
        Element helpers return real DOM nodes, accept an optional parent or shadow root, and preserve browser CSP. Tab helpers return a control with close(), closed and onclose. They accept HTTP(S) URLs, background booleans or active/insert/pinned options. Only that instance's created tabs can be closed. Limits: 8 connected handles per instance, 16 per script, 64 overall, and 32 opening attempts per script per minute. In Firefox, new tabs keep the source container, or use the container option; this needs helper access. Disabling or losing the native connection invalidates handles and leaves existing tabs open.
        
      
        Saved values
        GM_name value reads are synchronous after saved values load. GM.name storage methods return promises. Legacy writes update the local cache immediately and save in the background; save failures appear in the page console. Scripts using legacy reads or value listeners wait for their values before running, which can delay document-start. Values are JSON-compatible, local and private to each script (256 keys / 64 KiB).
        
      
        Menu commands
        Open the extension popup on a matching page to use its script commands. Refresh commands if a script adds or removes them while the popup is open. Changes from other tabs notify value listeners.
        
      
        Dependencies
        @require and named @resource files are prepared explicitly from absolute HTTPS URLs (HTTP is allowed on localhost). Optional #sha256=hex pins verify downloaded bytes. Limits: 8 libraries, 16 resources, 256 KiB per file and 1 MiB per script. Resource APIs: GM_getResourceText / GM.getResourceText and GM_getResourceURL / GM.getResourceUrl.
        
      
        Editor and organization
        Syntax highlighting and inline errors check source without running it. Use Go to error to jump to its location. Search and filter author @tag metadata and your local tags. Earlier and Later set the start order within each timing phase; saved-value loading and asynchronous work may finish later.
        
      
        Network requests
        GM_xmlhttpRequest provides callbacks and abort(); GM.xmlHttpRequest returns an abortable promise. Requests support FormData, ReadableStream bodies, user/password Basic authentication, upload callbacks, text, JSON, arraybuffer, Blob and document responses, with a 30-second timeout, 8 MiB upload and 8 MiB response limit. Up to five redirects follow by default; redirect: 'error' rejects them. Every destination must satisfy @connect when supplied; without it, the grant permits any HTTP(S) destination. anonymous: true omits cookies. Upload progress needs helper access; Firefox also needs it to follow redirects. See the user guide for all options and bounds.
        
      
        Clipboard, notifications and downloads
        These helpers require their exact @grant and Allow helper access in the script editor. GM_setClipboard / GM.setClipboard writes text or HTML (1 MiB); the modern form confirms completion with a promise. GM_notification / GM.notification returns a remove() control with onclick and ondone callbacks. GM_download / GM.download saves an HTTP(S) response through the browser, with a filename, callbacks and abort(); the modern form returns a promise. Downloads use @connect, a 16 MiB response limit, a 120-second HTTP timeout and unique filenames unless conflictAction is overwrite or prompt (prompt is unavailable in Firefox). They never open files automatically. See the user guide for supported options and lifecycle limits.
        
      
        Limits
        Full Violentmonkey compatibility is not claimed. Chrome and Edge support 10 isolated script worlds per document, including page bridges; broad regex or host rules can consume worlds on nearby URLs. Regex flags are unsupported; lookarounds and backreferences are evaluated with bounded work, and over-budget checks never run a script. .tld uses the bundled list of known public and private suffixes. Updates are never applied automatically: daily checks download newer versions for your review. Disabling prevents future runs and revokes live APIs, requests and menus; it cannot undo JavaScript or cookie writes already accepted by the browser.
        
      
        Trust
        Only enable scripts and dependencies whose code and site access you trust. Scripts can read and change matching pages, and a network grant lets them send data to their permitted destinations.
