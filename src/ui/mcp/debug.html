What this connection can do

Network sharing is optional. Open Network and start capture there; MCP stays connected while you switch sections. The agent can only read existing metadata; it cannot start, stop or clear capture. Headers and bodies are omitted, but URL paths may contain private information.

Change proposals are optional and need a server started with --allow-changes. Each one appears below for your review. Nothing is saved until you apply it, and an applied script stays off unless you choose Apply & enable. The agent cannot delete scripts or decide for you.

Source and error messages can contain private text. Cookie jars, saved GM values and page content are outside this connection’s access. Agents cannot run code or change settings.

      Setup and capture limits

      Use the default local stdio connection, or the optional authenticated localhost HTTP connection. Both require the same browser approval above. No package installation is needed. See the setup guide for commands and client configuration.

      Captured userscript errors include wrapper exceptions, top-level-await rejections and errors reported by managed GM callbacks in native messaging worlds, including page scripts using the GM bridge. Connect before reproducing the error. Ordinary page-console messages, raw scripts and unrelated asynchronous errors still require browser developer tools.

      Proposals last only for this connection. Revert is available for changes you applied during it; afterwards, edit the script in Modules & scripts.
