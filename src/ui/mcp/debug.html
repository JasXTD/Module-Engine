What this connection can read

Network sharing is optional. Open Network in another tab and start capture there. Keep both pages open to capture while debugging. The agent can only read existing metadata; it cannot start, stop or clear capture. Headers and bodies are omitted, but URL paths may contain private information.

Source and error messages can contain private text. Cookie jars, saved GM values and page content are outside this connection’s access. Agents cannot run code or change scripts and settings.

    Setup and capture limits

    Use the default local stdio connection, or the optional authenticated localhost HTTP connection. Both require the same browser approval above. No package installation is needed. See the setup guide for commands and client configuration.

    Captured userscript errors include wrapper exceptions, top-level-await rejections and errors reported by managed GM callbacks in native messaging worlds, including page scripts using the GM bridge. Connect before reproducing the error. Ordinary page-console messages, raw scripts and unrelated asynchronous errors still require browser developer tools.
