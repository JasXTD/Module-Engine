What this log can show

Browser-reported HTTP(S) requests and responses, including WebSocket handshakes. A row describes one request or redirect hop. Some browser, cache and blocked-request events may be unavailable; this is not a complete packet capture.

Other apps, response bodies, request bodies, headers and WebSocket messages are outside this log. A failed request is not proof of a Module Engine block; the browser error is shown when available.

Capture is off by default. Private tabs and requests whose context cannot be verified are excluded. A background restart stops capture. Retained entries use session memory and are cleared when the extension is reloaded or the browser restarts. URL paths can still contain private information; review exports before sharing.
